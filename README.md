# 面向脑部肿瘤的纵向多模态 MRI 生成与预后研究

本项目为东南大学 2026 年校院级 SRTP 创新训练项目，聚焦脑部肿瘤的个体化预后评估。项目以脑胶质瘤为主要研究对象，将患者历史多模态 MRI、临床信息、治疗信息和随访记录联合建模，探索从“生成未来影像”到“评估生存风险”的一体化研究流程。

## 研究背景

脑部肿瘤的病情进展和治疗反应通常体现在连续的影像随访中。仅依据单一时点的影像进行预后判断，难以充分利用患者个体差异和纵向变化信息。本项目希望让模型学习同一患者在治疗过程中的影像演变规律，并在指定未来时间点生成可能的随访 MRI，为病情分析和生存时间评估提供更丰富的信息。

## 核心目标

- 构建患者个体化的纵向多模态 MRI 生成方法，预测指定未来时间点的三维脑部影像。
- 融合年龄、性别、病史、治疗方式、治疗过程和目标时间等信息，实现可控的影像生成。
- 从生成影像中提取肿瘤变化和影像特征，用于生存时间与风险预测。
- 开发集影像生成、纵向对照、生存曲线和指标展示于一体的科研原型系统。

## 技术路线

1. **纵向影像生成**：以历史多模态 MRI、治疗信息及目标随访时间为输入，采用三维 VAE 与潜空间条件生成模型，学习初始影像到未来影像的变化过程。
2. **文本条件控制**：将患者状态和治疗过程整理为结构化临床文本，通过文本编码器与影像编码器的特征对齐及交叉注意力融合，控制指定时间点的 MRI 生成。
3. **生存预后分析**：从生成的随访 MRI 中提取病变形态及相对初始影像的变化特征，结合患者和治疗信息，采用 DeepHit 等方法输出生存概率曲线和风险评分，并与 Cox 模型进行对照。
4. **原型系统展示**：支持数据导入、未来影像生成、真实与预测随访影像对照、变化可视化及预后结果导出。

## 项目特色

- 将纵向影像生成与生存预后分析衔接为完整研究链路。
- 同时利用历史影像、患者个体信息和治疗信息进行条件控制。
- 在三维潜空间开展建模，兼顾空间结构与计算效率。
- 通过可视化界面展示肿瘤变化和预后结果，保存可复现的实验记录。

## 当前进展

项目组已整理多套脑肿瘤医学影像数据集，并在 CFB-GBM 数据上完成纵向增强 T1 MRI 预测、数据预处理、患者级划分、模型推理、评价指标计算及变化图输出等基础实验。目前已构建条件流匹配和 I²SB 桥扩散原型，后续将继续完善患者与治疗文本条件、三维生成质量及生存预测模块。

## 预期成果

- 面向脑胶质瘤的纵向 MRI 生成与生存分析研究框架；
- 可复现的数据处理、实验配置与评价流程；
- 集影像生成、纵向对照和预后展示于一体的科研原型系统；
- 软件著作权、研究论文初稿及项目结题材料。
