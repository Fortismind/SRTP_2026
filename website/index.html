01 / RESEARCH PREMISE

静态快照，
回答不了动态演化。

现有模型常在单一时间点提取影像特征，再映射到生存标签。但肿瘤在治疗与时间作用下持续改变， 静态判别与疾病演进之间存在明显错位。

SINGLE SCAN STATIC

影像快照 → 提取特征 → 生存标签

无法回答“接下来会怎样变化”

核心研究问题
从生成轨迹中提取的动态特征，能否为生存风险分层提供超越单时间点静态影像的增量预后信息？

RESEARCH STATUS / METHOD POSITIONING
STABLE PATH Cox + DeepHit

承担主要生存建模与核心验收，是稳定、可解释的基线主路径。

MAIN INNOVATION SDPM

团队自行实现的生成式创新路径，在稳定主路径之后进行验证。

SECONDARY EXPLORATION / OPTIONAL Censored Flow Matching / CFM

用于探索删失结局下的连续时间流匹配；不作为核心验收指标或结题前置条件。
