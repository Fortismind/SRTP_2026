# CFB-GBM：基线到随访增强 T1 的 I²SB 测试工程

这是一个实际运行的、轻量的纵向 MRI **算法原型**。输入患者放化疗前基线 t0 增强 T1 及实际间隔（周），生成 t1 增强 T1。t0 不自动等同于术前。这里没有生存预测、治疗效果因果推断、未来肿瘤分割或临床诊断系统。

## 先看什么

- `reports/实验报告.md`：实际环境、训练预算、独立测试结果、失败和限制。
- `reports/data_audit.json`、`data/manifest.csv`：真实文件核对结果和排除原因。
- `results/i2sb_short/summary.json`、`per_patient.csv`：患者级独立测试结果。
- `results/i2sb_short/患者编号/comparison.png`：基线、真实随访、生成随访、绝对误差，以及真实变化和预测变化。
- `reports/overfit.json`：训练患者两个切片的小样本拟合检查，必须与独立测试区分。

## 方法：为什么是 I²SB

已核对本机论文标题为 **I²SB: Image-to-Image Schrödinger Bridge**，并阅读方法部分与官方核心实现。论文主要做图像恢复；我们将其改造成同患者跨时间 MRI 的条件生成，不能据此宣称论文已验证肿瘤进展预测。

定义 `x0=真实 t1 随访`，`x1=可观测 t0 基线`。注意这里的下标是**桥端点**，与临床 t0/t1 命名相反。算法内部扩散时间用 `τ∈[0,1]` 表示；临床时间用 `weeks`，两者各自编码，不能混用。

设 `B(τ)=∫₀^τ β(u)du`、`S=B(1)=0.5`、`A(τ)=S-B(τ)`。采用正的对称噪声日程 `β(τ)=S/0.525 × [0.05+0.95 sin²(πτ)]`，用解析积分计算 B。

论文公式 11 的桥分布是：

`q(xτ | x0,x1)=N(A/S × x0 + B/S × x1, B×A/S × I)`。

训练采样 `τ∈{1/64,...,64/64}`，采用公式 12 与官方相同的归一化残差 MSE：

`E ||εθ(xτ, x1, τ, weeks) - (xτ-x0)/sqrt(B(τ))||²`。

这里的目标不只是加入桥状态的标准高斯噪声 ε；它包含两个端点的差异。网络显式拼接桥状态和基线图像，扩散时间正弦嵌入与临床 `log(1+weeks)` 标准化值进入每个残差块。间隔均值/标准差只使用训练患者。

推理从 `xτ=1=x1` 开始，先计算 `x0_hat=xτ-sqrt(B(τ))×εθ`，裁剪到训练范围 `[-1,1]`。对 `s<τ`，按解析反向后验更新：

`x_s=(1-B(s)/B(τ))×x0_hat + B(s)/B(τ)×xτ + sqrt(B(s)×(1-B(s)/B(τ)))×z`。

最终 s=0 的方差精确为 0，返回估计的随访。训练不取 τ=0，避免除零；τ=1 的桥方差精确为 0，仍可以计算训练标签。64 个桥网格、默认 16 次网络评估，生成过程中保留随机噪声；没有启用 OT-ODE。官方实现含端点步长的离散累计和，这里改为精确积分端点，详见 `THIRD_PARTY.md`。桥均值不是随便规定的线性插值，方差和反向转移均由同一桥公式约束，且已做分布检查。

轻量 2D U-Net 初始通道 16，约 14 万参数，GroupNorm，无预训练权重，无多卡依赖。确定性对照使用同结构、同临床条件，预测基线残差并用图像 MSE 训练。恒等对照直接使用基线。

## 数据与防泄漏

原始目录为 `E:\srtp项目\ADNI-T1-PET(AV45 FDG)等4个文件\CFB-GBM`。只读原始 NIfTI/TSV，不修改 E 盘，不复制整个数据集。按真实文件名核对 t0/t1 增强 T1；排除无患者号汇总行、缺失文件、无效间隔、空/异常图像、空间或粗配准检查失败者。治疗标签只保存为可选信息，不作为入选条件，也没有使用生存字段。

`data/splits.json` 是固定种子 20261025 的患者级 70%/15%/15% 划分。所有切片归属同一患者集合。默认验证只取固定的前 4 位验证患者、每位均匀 8 张基线覆盖切片，以减少短训练耗时；最佳权重按这些验证数据的等患者脑区 MAE 选择。测试患者在选定权重后才生成和评价。小样本过拟合模型独立训练且不复用权重。

逐对记录方向、间距、qform/sform、完整仿射和世界坐标范围。重定向到最接近 RAS 的轴序；保留原有轻微斜位，不再次强制去斜位。相同数组尺寸不足以证明对齐：还比较物理网格、脑前景支持区重叠及强度相关性，保存全部患者的中间切片接触图。已有一致网格和较高粗配准指标的配对避免重复配准。若网格不同但物理范围充分重叠，则依据仿射把随访重采样到基线网格（这是重采样，不是额外配准）；粗一致性不合格者明确排除，需后续人工检查/配准。本次实际采用的动作分布见报告。

每位患者的**基线**决定处理规则：去除正强度低值及 2% 高分位以下值，保留最大 3D 连通分量，逐层填洞作为脑前景近似掩膜；本地可视化显示已有脑区提取特征，但这不是专家脑分割。取此支持区的包围盒，XY 加 4 体素边界、补成正方形后缩放到 128×128；保留覆盖范围内所有轴向层。配对共用同一盒、同一补边、同一强度变换；没有分别随机裁剪。MRI 双线性/仿射线性插值，掩膜最近邻。

归一化用基线正强度 0.5 和 99.5 分位，**同时应用于两张影像**，裁剪到 [0,1]；目标不提供统计量。因此真实随访亮度超出基线范围会饱和，跨扫描强度差可能被误认成变化，是本原型的重要限制。缓存为 float16，每位保存变换 JSON。训练输入再映射到 [-1,1]，采样输出映射回 [0,1]。未来可增加训练集规则的标准化/偏场校正，不能根据测试目标独立匹配强度。

基线 GTV 仅在物理网格相同且有效时用于**附加评价**，不参与选片和模型条件。它是基线放疗规划靶区，既不是随访分割，也不是标准肿瘤亚区。网格不同者不强行叠加，缺失者仍可入组。核心清单保留可选治疗字典，网络和数据模块可继续扩展 FLAIR、治疗/临床条件，但新增条件需先确认预测时可获得。

`reports/gtv_overlay_*.png` 为所有可用基线 GTV 的最大面积层叠加图，仅用于标签空间粗查；该选层规则不用于模型选片或主结果示例。这些粗查不能替代放疗专家逐层核对。

## 评价的含义

MAE、PSNR 的评价范围为基线脑前景近似掩膜内；`data_range=1`。PSNR 按每切片区域 MSE 计算 `-10log10(MSE)`，再先平均切片、后平均患者。SSIM 使用 7×7 窗和 data_range=1，只在基线掩膜腐蚀 3 像素后的中心点汇总，避免窗口黑背景主导。GTV 附加指标在基线靶区与支持区交集内计算；没有真实随访分割，不计算肿瘤 Dice。

区域不足 10 个模型像素的切片不计入该区域指标（脑区/GTV 各自判断），JSON 的 slices 记录实际汇总数量；SSIM 没有有效内部窗口时记为 NA，不强行补零。零 MSE 用 1e-12 做数值保护，PSNR 上限为 120 dB。变化图展示归一化强度差，红色为增加、蓝色为降低，不自动等于肿瘤增大或缩小。

每个患者先汇总其所有覆盖切片，再做患者等权平均；逐患者 CSV/JSON 可追踪变化。恒等与模型使用相同目标、归一化、覆盖和患者。报告预测变化幅度、真实变化幅度，避免把复制基线误判成有价值的预测。

每例仅用预先固定的随机种子生成一次；不利用真实目标挑选种子或最好样本。每个 8 切片批次的种子是 `7391 + patient_id*10000 + 批次首切片索引`，写入 sidecar；换 batch 可能换样本。所有测试患者均输出对照图，报告展示固定测试表中编号最小的三例，中间层由基线覆盖决定。多个采样的差异即使以后报告，也不是校准过的临床不确定性。

## Windows 运行

已配置项目内 `.venv`，通过 `.pth` 复用 `D:\ai\.venv` 的 CUDA PyTorch。补充依赖只装在新项目；既有环境不改动。首次配置可运行 `bootstrap_reuse.ps1`。实际加载版本见 `reports/environment.json`；从零配置可建立独立 Python 3.10 环境并 `pip install -r requirements.lock.txt`（会下载完整 PyTorch，本次没有这样做）。

在 PowerShell：

```powershell
cd D:\ai\cfb_gbm_i2sb_test
$env:PYTHONUTF8='1'
# 首次完整运行；已有训练权重时请使用新 --run 名称，或显式 --resume。
.\run_pipeline.ps1
# 已有缓存时
.\run_pipeline.ps1 -SkipAudit
```

单独执行：

```powershell
.\.venv\Scripts\python.exe audit_data.py
.\.venv\Scripts\python.exe verify.py
.\.venv\Scripts\python.exe verify.py --overfit --steps 600
.\.venv\Scripts\python.exe train.py --kind i2sb --run i2sb_short
.\.venv\Scripts\python.exe train.py --kind regression --run regression_short
.\.venv\Scripts\python.exe evaluate.py --checkpoint weights/i2sb_short/best.pt --run i2sb_short
.\.venv\Scripts\python.exe make_report.py
```

`configs/short.json` 默认主模型和回归各 600 步、batch 8，每个训练最多 20 分钟；验证每 100 步执行。日志包含实际步数和时间。训练按患者均匀随机抽样，再取该患者随机切片。不同患者切片量不同，不会让大体积患者自动获得更多更新。

为避免意外覆盖，训练发现同名 last.pt 时会拒绝从头运行；复用缓存不等于覆盖实验。`run_pipeline.ps1` 用于首次全流程，已有交付结果时建议按单步命令和新的 `--run` 名称进行新实验。清单/缓存重建会写入项目内同名文件，重新划分后的实验不能与旧 checkpoint 混用。

断点续训：将配置的 steps 调大（这是总目标步数），然后：

```powershell
.\.venv\Scripts\python.exe train.py --kind i2sb --run i2sb_short --resume weights/i2sb_short/last.pt
```

checkpoint 包含模型、AdamW、步数、最佳验证值、CPU/CUDA/NumPy/Python RNG 状态及配置哈希。只加载自己生成的可信 `.pt` 文件。每次启动的时间预算重新计时；同配置同设备尽量复现，但 CUDA/驱动变更不保证跨版本逐位一致。

本地推理没有 target 参数：

```powershell
.\.venv\Scripts\python.exe infer.py `
  --baseline 'E:\实际患者目录\t0\患者号_t0_t1gd.nii.gz' `
  --weeks 23 `
  --checkpoint weights/i2sb_short/best.pt `
  --output results/my_prediction --seed 7391 --patient-id 0
```

该例路径是参数示意；本次实际患者的可复制命令见实验报告。输入必须与本数据预处理分布接近，不能保证任意医院原始含颅骨扫描直接可用。`infer.py` 生成阶段独立读取基线，不读含目标的 NPZ 缓存；`evaluate.py` 在生成完成后才打开目标缓存计算评价。

## 3D Slicer 打开方式

用 Add Data 同时加载患者结果目录下 `prediction_normalized.nii.gz`（0—1）和 `coverage.nii.gz`；也可加载 `prediction_baseline_intensity.nii.gz`（用基线分位数反变换的任意 MRI 强度单位，并非定量物理单位）。输出恢复原始基线的 shape、方向和仿射，qform/sform 同步；可与原始基线叠加。需要真实随访时，用清单里的 target 文件作参考。

**coverage=1 才是模型覆盖的基线脑支持区**，其余预测值为 NaN。图像处理器对 NaN 的显示可能不同，务必叠加 coverage；可用 Slicer 的 Volumes/Window-Level 调整到 0—1。没有声称生成原始全头体积，也没有把剩余区域复制成预测。输出 3D 文件来自独立 2D 切片，上下层可能不连续；升采样回原始尺寸不会恢复丢失的高频细节。评价在 128×128 模型网格上，不等同原生高分辨率体积评价。

## 目录

`cfb/` 为算法/数据/指标库；根目录脚本为检查、验证、训练、推理、评价、报告入口；`configs/` 为预算配置；`data/` 为清单和划分；`cache/` 为必要配对缓存；`weights/` 为各独立实验权重；`logs/` 为逐步训练记录；`reports/` 为检查、数值与实验报告；`results/` 为逐患者预测、指标、图像、NIfTI 和空间覆盖；`references/` 为论文核对和官方参考记录。

运行成功只说明工程闭环成立；相似度改善必须看独立患者对照；可靠肿瘤预后需要更充分训练、专家审核配准和分割、更多临床治疗条件、外部验证与前瞻性评价。三者不能混为一谈。
